# ReMart — Luxury Commerce Basic Website

Multi-page HTML/CSS/JavaScript starter for a luxury and premium-goods marketplace.

## Pages
- index.html — Home
- collection.html — Collection/filtering
- product.html — Product detail + add-to-bag
- concierge.html — Concierge request
- about.html — Brand story
- checkout.html — Account-free demo checkout
- login.html — Login visual/demo only
- signup.html — Signup visual/demo only

## Structure
/project-root
├── assets/css/style.css
├── assets/css/dark-mode.css
├── assets/css/rtl.css
├── assets/js/main.js
├── assets/js/dashboard.js
├── assets/images/logo.svg
└── HTML files

## Notes
- Account links redirect to login.html.
- Checkout and cart use localStorage and do not require an account.
- No real payment/account backend is connected.
- Replace placeholder product artwork with licensed product photography later.
- Fonts load from Google Fonts when online.
